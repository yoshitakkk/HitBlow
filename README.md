# Hit & Blow

4桁の重複しない数字を推理する、日本語対応のHit & Blowゲームです。ひとり用CPU戦と、ルームコードで遊ぶオンライン対戦に対応しています。

## 起動方法

Node.js 18以降を用意し、プロジェクトのディレクトリで実行します。

```sh
npm start
```

ブラウザで `http://localhost:3000` を開きます。オンライン対戦を別の人と遊ぶ場合は、このアプリを両方の端末からアクセスできるサーバーに配置してください。HTTPSで公開すると、対戦接続にもWSSが使われます。

## 遊び方

- **ひとりで遊ぶ:** CPUが設定した4桁を推理します。
- **オンライン対戦:** ルームを作成してコードを共有するか、コードを入力して参加します。双方が秘密の4桁を決めると、交互に相手の数字を推理します。
- **HIT:** 数字と位置の両方が一致。
- **BLOW:** 数字は使われているが、位置が違う。

数字は先頭の0を含めて使えますが、同じ数字を複数回使うことはできません。オンライン対戦では、秘密の数字はサーバー内の判定にのみ使われ、相手には送信されません。ルームはどちらかの接続が切れると終了します。
