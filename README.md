# Hit & Blow

4桁の重複しない数字を推理する、日本語対応のひとり用Hit & Blowゲームです。

## 起動方法

Node.js 18以降を用意し、プロジェクトのディレクトリで実行します。

```sh
npm start
```

ブラウザで `http://localhost:3000` を開きます。

## 遊び方

- **ひとりで遊ぶ:** CPUが設定した4桁を推理します。
- **数字の入力:** 数字のボタンを4つ選び、「推理する」を押します。選択済みの数字は再び選べません。「1桁戻す」で最後に選んだ数字を取り消せます。
- **ギブアップ:** プレイ中に「ギブアップして答えを見る」を押すと、正解を確認できます。
- **HIT:** 数字と位置の両方が一致。
- **BLOW:** 数字は使われているが、位置が違う。

数字は先頭の0を含めて使えますが、同じ数字を複数回使うことはできません。
