# Hit & Blow

4桁の重複しない数字、または6色のボールから選ばれた4色の並びを推理する、日本語対応のひとり用Hit & Blowゲームです。

## 起動方法

Node.js 18以降を用意し、プロジェクトのディレクトリで実行します。

```sh
npm start
```

ブラウザで `http://localhost:3000` を開きます。

## 遊び方

- **モード選択:** ホーム画面で数字モードまたは6色ボールモードを選びます。
- **数字モード:** CPUが設定した、重複しない4桁の数字を推理します。先頭に0も使えます。
- **6色ボールモード:** 赤・黄・ピンク・青・緑・紫から重複しない4色の並びを推理します。
- **入力:** ボタンを4つ選び、「推理する」を押します。選択済みの数字や色は再び選べません。「1桁戻す」で最後の選択を取り消せます。
- **ギブアップ:** プレイ中に「ギブアップして答えを見る」を押すと、正解を確認できます。
- **HIT:** 数字と位置の両方が一致。
- **BLOW:** 数字は使われているが、位置が違う。

各モードとも、同じ数字または色を複数回使うことはできません。
