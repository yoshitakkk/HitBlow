# Hit & Blow

4桁の重複しない数字、または6色のボールから選ばれた4色の並びを推理する、日本語対応のHit & Blowゲームです。ひとり用と2人のオンライン対戦に対応しています。

## 起動方法

Node.js 22以降とnpmを用意し、プロジェクトのディレクトリで実行します。

```sh
npm start
```

ブラウザで `http://localhost:3000` を開きます。この方法ではひとり用モードのみ利用できます。

### オンライン対戦のローカル実行

Cloudflare Workersのローカル環境を使用します。

```sh
npm install
npm run dev
```

表示されたURLを開いてください。同じURLを別のブラウザや別のタブで開くと、2人の動作を確認できます。`npm start` やHTMLファイルの直接表示ではオンライン対戦は動作しません。

### Cloudflareへのデプロイ

Cloudflareアカウントを用意し、WorkersとSQLiteベースのDurable Objectsを利用できるようにします。初回はWranglerにログインし、以下を実行します。

```sh
npm install
npx wrangler login
npm run deploy
```

表示されたWorkersのHTTPS URLを2人で利用します。[wrangler.jsonc](./wrangler.jsonc) の設定で静的ファイルと対戦用Durable Objectを同じWorkerにデプロイします。WorkersとDurable Objectsの使用量や料金はCloudflareのプラン・制限に従います。

サーバー側のテストは `npm test` で実行できます。

## 遊び方

- **モード選択:** ホーム画面で数字モードまたは6色ボールモードを選びます。
- **数字モード:** CPUが設定した、重複しない4桁の数字を推理します。先頭に0も使えます。
- **6色ボールモード:** 赤・黄・ピンク・青・緑・紫から重複しない4色の並びを推理します。
- **入力:** ボタンを4つ選び、「推理する」を押します。選択済みの数字や色は再び選べません。「1桁戻す」で最後の選択を取り消せます。
- **ギブアップ:** プレイ中に「ギブアップして答えを見る」を押すと、正解を確認できます。
- **HIT:** 数字と位置の両方が一致。
- **BLOW:** 数字は使われているが、位置が違う。

各モードとも、同じ数字または色を複数回使うことはできません。

### オンライン対戦

1. 「オンライン対戦」から数字または6色ボールを選んで部屋を作り、招待URLを相手に送ります。
2. 2人がそれぞれ重複しない4つの数字または色を自分の答えとして設定します。対戦終了まで相手の答えは表示されません。
3. 部屋を作った人から交互に推理し、先に相手の答えを当てた人の勝ちです。「降参する」でも対戦を終了できます。

部屋は2人まで参加でき、作成から24時間で失効します。招待URLを知っている人が参加できるので、対戦相手以外に共有しないでください。参加情報は各タブのセッションストレージに保存されるため、同じタブでの再読み込み後は再参加できますが、タブを閉じた後や別のブラウザでは同じプレイヤーとして復帰できません。通信中に画面を離れても自動的に降参にはなりません。
